# ADMA — личные финансы (PWA)

Минималистичное офлайн-приложение для учёта личных доходов и расходов. Все данные хранятся локально в `IndexedDB` на устройстве пользователя без серверов, трекеров и внешних CDN.

## Установка на телефон
- **iPhone (Safari):** откройте ссылку в Safari → **Поделиться** → **На экран «Домой»** → **Добавить**.
- **Android (Chrome):** откройте ссылку в Chrome → меню (`⋮`) → **Установить приложение**.

## Импорт и резервное копирование
- **Импорт CSV:** `Настройки → Импорт CSV` (`date,type,amount,category,comment`, разделители `,` и `;`, UTF-8 BOM, защита от дублей и автосоздание категорий).
- **Бэкап JSON:** `Настройки → Бэкап JSON` сохраняет полную копию базы (`transactions`, `categories`, `settings`).
