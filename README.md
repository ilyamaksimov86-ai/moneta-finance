# Монета — личные финансы (PWA)

Минималистичное офлайн-приложение для учёта личных доходов и расходов. Все данные хранятся локально в `IndexedDB` на устройстве пользователя без серверов, трекеров и внешних CDN.

## Установка на телефон

### iPhone (Safari)
1. Откройте ссылку на приложение в **Safari**.
2. Нажмите **Поделиться** (квадрат со стрелкой вверх) → **На экран «Домой»** → **Добавить**.

### Android (Chrome)
1. Откройте ссылку на приложение в **Chrome**.
2. Нажмите меню (`⋮`) → **Установить приложение** (или **Добавить на главный экран**).

## Импорт и резервное копирование
- **Импорт CSV:** `Настройки → Импорт CSV` (поддерживает `date,type,amount,category,comment`, разделители `,` и `;`, UTF-8 BOM, защиту от дублей и автосоздание категорий).
- **Бэкап JSON:** `Настройки → Бэкап JSON` сохраняет полную копию базы (`transactions`, `categories`, `settings`).

## Обновление приложения
1. Внесите правки в файлы (`index.html`, `styles.css`, `db.js`, `app.js`).
2. При изменении кода обновите версию кэша `CACHE_NAME` в `sw.js` (например, `moneta-cache-v2`).
3. Закоммитьте и запушьте изменения в ветку `main` — GitHub Pages обновит сайт автоматически.
